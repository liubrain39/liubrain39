# MinshengLiu — image editing tools and guides

I operate [Image to Image](https://imagetoimage.dev/), a web editor for revising
an existing photo with a source image and a text instruction. This page and the
resources below are my own publications, not independent recommendations.

## Start with one clear edit

- [Open the image editor](https://imagetoimage.dev/#editor): upload a JPG, PNG or
  WebP, describe the change, compare the reviewed result and download it. No
  product account is required. Images are uploaded when an edit is requested.
- [Use the free Image Editing Prompt Builder](https://liubrain39.github.io/image-to-image-prompt-guide/):
  assemble an instruction from one change and the details to preserve. This
  separate text tool works locally without uploading photos, generating images
  or calling an AI API. Its six templates are starting instructions.
- [Read the prompting guide](https://imagetoimage.dev/guide): learn how to check
  product shape, proportions, text, material, color and shadows after an edit.

## One actual product-photo example

The [white-chair background example](https://imagetoimage.dev/image-to-image/product-photo-background#real-example)
includes the original photo, exact instruction and real generated output. It
produced a green studio scene, but the framing, seat edge and leg details also
changed. It is one operator-produced example, not a model benchmark or a promise
of pixel-identical product preservation. Use conventional cutouts/compositing
when the original product pixels must remain unchanged.

## QuietTake — browser audio cleanup

[QuietTake Noise Remover](https://noiseremover.site/) cleans background noise from
short voice recordings with RNNoise running locally in the browser. No account
or audio upload is required.

Choose Gentle, Balanced or Strong processing, compare the original and cleaned
recording, then download a WAV file. Files must be no larger than 50 MB and no
longer than 5 minutes. Input-format support depends on the browser.

Useful for short voice notes, interview excerpts, podcast clips and spoken
tutorials with steady background noise.

## ModLab — Universal Modder guides

I maintain [ModLab](https://modlabguides.online/), an independent Universal Modder guide.
The [free Mindustry homing lab](https://modlabguides.online/workshop/mindustry-homing)
includes original MIT source, a mod ZIP, screenshots, a video montage and recovery steps.
It uses Mindustry's built-in JSON/JavaScript mod API. Playing the supplied ZIP needs
no coding agent, fal API key or paid assets; agent usage charges may apply when editing.

Recorded tests cover Mindustry 160.7, mod 0.1.0 and macOS 15.7 in single-player.
Other systems and multiplayer remain untested. Recorded runs use a fixed arena
with scripted targets.
